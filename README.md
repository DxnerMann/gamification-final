# StudyGarden — Gamification Final

Interactive Apple-style presentation for **StudyGarden**  
(“Grow your knowledge — one seed at a time.”)

## Repo layout

| Folder | Purpose |
|--------|---------|
| [`presentation-slides/`](presentation-slides/) | Vite + React talk deck. Each slide is one screen, with cozy garden decoration. |
| [`demo-app/`](demo-app/) | Placeholder for an optional product demo (empty for now) |

## Local

```bash
cd presentation-slides
npm install
npm run dev
```

## Present

1. Open the dev server (or the GitHub Pages URL).
2. Press **P** for Present / fullscreen.
3. Navigate with **← →** or **↑ ↓**. Each slide fills exactly one screen.
4. **End** jumps to the summary poster.
